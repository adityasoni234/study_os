# StudyOS — 3-minute judge demo script

> Before demoing: **Settings → Reset demo data** for a clean state. Desktop window, light mode.

## The golden path

0. **Landing page** (`/welcome`) — one line on what StudyOS is, then **Get started** →
   sign in with Google, an email account, or **Continue as demo learner** (fastest for judging).
1. **Home** — point at *Today's Mission: Precision & Recall* ("the app always answers: what should
   I do now?"). Note the violet strip: *"Adapted for you — recall questions tripped you up on
   Tuesday"* → the system knows the learner.
2. Click **Roadmaps → Machine Learning** — the journey timeline: Foundations done, *Classification
   Metrics — You are here*, later topics locked. Click the current node → side panel → **Learn with
   Tutor**.
3. **1:1 Tutor** (the hero):
   - Intro references last session (confusion matrix, 88%). Click **Let's go**.
   - Explanation arrives as teaching blocks: two question-framed callouts, colored formulas, a
     **citation chip** (click it — source excerpt with highlighted passage).
   - Click **Test me ✏️** → inline Quick Check (hospital screening scenario).
   - **Answer "Precision" — deliberately wrong.** The tutor never shames: *"You're close — this is
     the classic mix-up"*, re-teaches with the false-alarm/miss framing and a memory hook, then
     flips the scenario (spam filter).
   - Answer **"Precision"** (now correct). Mastery chip animates **65% → 72%**, toasts fire:
     *Mastery updated* + *Roadmap adapted*. Mission step 1 completes on Home.
   - Optionally show **Explain differently** (7 styles) next to the input.
4. Click **Practice 5 questions** → quiz setup → run 2–3 questions (keyboard 1–4 works) → results:
   score ring, mastery delta, Strong / Improving / Needs practice, roadmap updated.
5. **Notebook** — sources on the left; **Chat** answers with citation chips; ask something
   off-source (e.g. "capital of France") → honest *"not in your sources"* + choice. Flip through
   **Study Guide / Mind Map / Flashcards / StudyCast** (30s total).
6. **Opportunity Radar** — *HackForEd, 94% match*, explainable: ✓ Python ✓ ML ⚠ RAG needs practice.
   Click **Prepare me** → generated 6-day plan; Day 2 is RAG with **Open with Tutor** → the tutor
   teaches RAG for the hackathon. Click **Start preparation**.
7. **Growth** — dimensions, momentum, knowledge map showing Precision & Recall freshly updated.
8. Close with **Wellbeing → I need a reset** (2-minute breathing) and **Inner Growth** (authentic
   verse, AI reflection clearly labeled) — "it supports the learner as a human being."

## One-line close

*"StudyOS doesn't just answer questions — it knows what you should learn next, teaches until you
master it, and connects that mastery to real opportunities."*
